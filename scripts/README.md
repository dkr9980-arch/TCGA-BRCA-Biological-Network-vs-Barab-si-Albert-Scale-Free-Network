# R Analysis Scripts

This directory contains the R scripts used for the TCGA-BRCA biological network and Barabási–Albert scale-free network analysis.

## Workflow

1. `01_data_preparation.R` – Data preparation
2. `02_differential_expression.R` – Differential expression analysis
3. `03_correlation_network.R` – Biological correlation network construction
4. `04_scale_free_BA_network.R` – Barabási–Albert network generation
5. `05_network_properties.R` – Network topology and property analysis
6. `06_pathway_enrichment.R` – Pathway and functional enrichment analysis
7. `07_hub_gene_analysis.R` – Hub gene identification
8. `08_visualization.R` – Visualization of network and analysis results
