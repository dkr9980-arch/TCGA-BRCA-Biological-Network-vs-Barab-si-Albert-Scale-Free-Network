# Results

This directory contains the outputs generated from the TCGA-BRCA biological network and Barabási–Albert scale-free network analysis.

## Results included

- Network visualizations
- Network topology statistics
- Degree distribution analysis
- Hub gene analysis
- Gene Ontology enrichment results
- Reactome pathway enrichment results

## Organization

- `figures/` – Network and enrichment plots
- `hub_genes/` – Identified hub genes
- `GO_enrichment/` – Gene Ontology enrichment results
- `Reactome/` – Reactome pathway analysis results
